# Punctaj laborator
- Descrierea inițială a proiectului: 2 puncte (S3);
- Crearea repository-ului: 2 puncte (S4);
- Commit-uri cu conținut în cel puțin 3 săptămâni distincte (etapele intermediare: S6, S9, S12): 3 x 2  = 6 puncte;
- Evaluarea prezentării orale: 30 puncte.
- Rapoarte lucrări laborator: 10 x 1 = 10 puncte. 

#### Fiecare lucrare de laborator se va finaliza prin completarea unui raport și încărcarea acestuia pe Moodle.
